# portal-job (ポータルハブ) 🚀

> **地元の店舗と求職者を繋ぎ、持続可能な地域経済と業務のDXを実現するプラットフォーム**

---

## 📌 プロジェクト概要

**portal-job** は、地域に根ざした個人店・中小規模事業者（レストラン、カフェ、食堂など）と、その地域で働きたい求職者をダイレクトに結びつける、次世代型マルチエリア・マッチングプラットフォームです。

単なる「求人情報の掲載」に留まらず、店舗オーナーとスタッフ間のスケジュール調整を自動化する**スマートシフト管理（24時間～翌朝の夜間シフト対応）**、リアルタイムの**portal-job Chat**、および店舗イメージを高める**メディア管理システム**を統合し、地域社会における「雇用」と「業務DX」の課題をワンストップで解決します。

---

## 🏡 地元の課題解決のための開発背景

地方自治体や特定地域コミュニティにおける経済の持続可能性は、地元の店舗（カフェ、和食、洋食、食堂等）の活性化に直結しています。しかし、現在の地域社会は以下の深刻な課題に直面しています。

1. **求人媒体の掲載料高騰とアンマッチ**
   大手求人サイトは月々の掲載料が高額であり、地元の個人経営店や小規模事業者は持続的に募集を出すことが困難です。
2. **アナログな業務運営と過重な管理コスト**
   アルバイトやスタッフのシフト提出、調整、承認作業が未だに「紙のメモ」や「個人のSNSメッセージ」に依存しており、転記ミスやTimeZoneのズレによる勤怠トラブル、オーナーの過重な事務負担を生んでいます。
3. **地域内のつながりの希薄化**
   地元のファンやリピーターが「その店で働きたい」と思っても、店舗と求職者の間に安全で迅速なコミュニケーション（チャット等）の手段がありませんでした。

**portal-job** は、これらの「コスト」「業務負荷」「コミュニケーション」の壁を取り払い、地域コミュニティ内での最適なマッチングとデジタルシフト（DX）を推進するために開発されました。

## 🛠 今回のリファクタリングにおける高度な技術的アプローチ

企業の厳格な技術選考・コードレビューに耐えうる「最高品質 of クリーンコード」を目指し、プロジェクト全体に対して以下のリファクタリングを実施しました。

### 1. 🛡️ 安全な環境変数管理とセキュリティ
- **機密情報の完全排除**:
  データベース接続情報（`DATABASE_URL`）やCloudinaryの秘密キー、SupabaseのAPIトークンなど、過去のハードコードや開発時の残存データを完全に一掃し、すべてクリーンなプレースホルダーおよびテスト用ダミーデータに統一しました。
- **堅牢な環境変数設計**:
  バックエンド（Go/Python）およびインフラ設定（`docker-compose.local.yml`）において、`${VARIABLE:-default_value}` の形式に徹底的にリファクタリングし、万が一環境変数が未指定の場合でも安全にフォールバック、または安全な起動シグナルを出せるように設計を統一しました。
- **プロジェクトルートに `.env.sample` を配置**:
  新規開発者が即座に安全なローカル開発環境を再現できるよう、詳細なコメントと適切なプレースホルダー付きの環境変数サンプルを完備しました。


## 🗂️ レイヤー別アーキテクチャ

本プロジェクトは、スケーラビリティ、パフォーマンス、関心の分離（SoC）を追求した多層アーキテクチャを採用しています。

```
├── src/                    # フロントエンド (Next.js 15 App Router)
│   ├── app/                # Localized Page Routing (next-intl, [locale])
│   ├── components/         # 共通UI & ドメイン特有のコンポーネント群
│   │   ├── ui/             # Atomicなデザインシステム（Modal, Skeleton等）
│   │   └── ...             # 各ビジネスドメインのUI/UX（ShiftCalendar等）
│   └── lib/                # API通信 (Supabase JWT連携), カスタムフック
├── go-api/                 # メインAPIサーバー (Go 1.22+ / pgxpool)
│   ├── cmd/                # エントリーポイント
│   └── internal/           # データベース、認証、CORS、ルーティング
├── go-worker/              # バックグラウンドタスクランナー (Go)
│   └── internal/tasks/     # ジョブ自動期限切れ処理、Webプッシュ配信統計
└── backend/                # 補助用高速Webサーバー (Python FastAPI / SQLAlchemy)
```

## 🚀 開発環境のセットアップ

### 1. 環境変数の設定
プロジェクトルートにて、環境変数設定ファイルを作成します。
```bash
cp .env.sample .env
```
`.env` 内の各項目（データベースURL、Supabase、Cloudinary情報など）を、自身の開発用環境に合わせて編集します。

### 2. ローカル開発用コンテナの起動
Docker Composeを使用して、フロントエンド、バックエンド（Go/Python）、データベースをまとめて立ち上げます。
```bash
docker-compose -f docker-compose.local.yml up --build
```

### 3. フロントエンドの個別実行
```bash
npm install
npm run dev
```

### 4. 静的コード解析とビルド検証
```bash
# 型チェック
npx tsc --noEmit

# リンター
npm run lint

# E2Eテストの実行
npm run test:e2e
```
docker compose -f docker-compose.yml -f docker-compose.local.yml --profile api up -d --build frontend go-api
