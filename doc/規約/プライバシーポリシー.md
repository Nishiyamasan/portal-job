# プライバシーポリシー

本プライバシーポリシー（以下「本ポリシー」といいます。）は、portal-job運営事務局（以下「当事務局」といいます。）が提供する「portal-job」（以下「本サービス」といいます。）における、利用者の個人情報の取扱いについて定めるものです。

---

## 1. 取得する情報
当事務局は、本サービスの提供にあたり、次の情報を取得することがあります。

1. アカウント情報  
メールアドレス、表示名、プロフィール情報、認証関連情報

2. 投稿・応募・問い合わせ情報  
求人応募時の入力内容、店舗情報の投稿内容、お問い合わせ内容

3. 通信・利用情報  
IPアドレス、Cookie、端末情報、ブラウザ情報、アクセスログ、操作履歴

4. 外部サービス連携情報  
外部認証・外部ストレージ等の利用に伴い外部サービスから連携される情報

## 2. 利用目的
取得した情報は、次の目的で利用します。

1. 本サービスの提供、維持、改善
2. 本人確認、ログイン認証、不正利用防止
3. 求人応募・店舗運営機能・メッセージ機能の提供
4. お問い合わせ対応
5. 障害対応、セキュリティ監視、監査対応
6. 利用状況分析（統計化した情報による改善）
7. 規約違反行為への対応

## 3. 外部サービスの利用と国外移転
本サービスでは、機能提供のために外部サービスを利用しています。これに伴い、個人データが日本国外に保存・処理される場合があります。

| サービス名 | 用途 | 主な保存・処理地域（例） |
| :--- | :--- | :--- |
| Cloudflare | CDN / WAF / 配信基盤 | 米国その他グローバル |
| Cloudinary | 画像アップロード / 画像配信 / 画像変換 | 米国その他グローバル |
| Supabase | 認証 / DB | 日本（東京）を主とする設定 |
| さくらインターネット | API / サーバー実行環境 | 日本、米国等 |

当事務局は、委託先のセキュリティ措置を確認し、アクセス制御・暗号化通信・権限管理等の安全管理措置を講じます。

## 4. Cookie等の利用
本サービスは、ログイン状態の保持、利便性向上、アクセス解析のためにCookie等を利用します。  
利用者はブラウザ設定によりCookieを無効化できますが、その場合、一部機能が利用できないことがあります。

## 5. 第三者提供
当事務局は、次の場合を除き、個人データを第三者に提供しません。

1. 本人の同意がある場合
2. 法令に基づく場合
3. 人の生命・身体・財産の保護に必要で、本人同意取得が困難な場合
4. 公衆衛生の向上等に特に必要で、本人同意取得が困難な場合
5. 国の機関等への協力が必要で、本人同意により業務遂行に支障がある場合
6. 業務委託（ホスティング、認証、分析等）のために必要な範囲で提供する場合

## 6. 保有個人データの開示等（本人の権利）
利用者は、法令に基づき、当事務局に対して、自己の保有個人データに関する以下の請求を行うことができます。

1. 利用目的の通知
2. 開示
3. 訂正・追加・削除
4. 利用停止・消去
5. 第三者提供の停止

請求方法・本人確認方法・回答方法は、当事務局所定の手続によります。内容により回答まで相当期間を要する場合があります。

## 7. 保持期間
当事務局は、取得情報を利用目的達成に必要な期間保有し、不要となった情報は、法令上保存義務がある場合を除き、合理的な方法で削除または匿名化します。

## 8. 安全管理措置
当事務局は、個人情報の漏えい、滅失、毀損の防止その他の安全管理のために、次の措置を講じます。

1. SSL/TLS等による通信の暗号化
2. アクセス権限管理および認証情報の適切な管理
3. サーバー・ミドルウェア等の更新、脆弱性対応
4. ログ監視および不正アクセス対策

## 9. 他サイトへのリンク
本サービスから外部サイトへ遷移した場合、遷移先サイトにおける個人情報の取扱いについて当事務局は責任を負いません。

## 10. 本ポリシーの変更
当事務局は、法令変更やサービス変更に応じて本ポリシーを改定することがあります。  
重要な変更を行う場合は、本サービス上で事前に周知し、改定日以降に効力を生じるものとします。

## 11. お問い合わせ窓口
本ポリシーに関するお問い合わせ、開示等請求は、本サービス内のお問い合わせフォーム（`/contact`）からご連絡ください。
